# Pichi Voice

**Говорите вместо печати. Сохраняйте встречи на своём устройстве.**

Голосовой ввод на Mac, локальная запись и расшифровка встреч на Mac, iPhone и iPad. Меньше печати и больше контроля над своими записями.

[English](README.md) · [Сайт](https://pichi.ai/ru/voice) · [Релизы](https://github.com/Pichi-AI/pichi-voice/releases) · [Руководство](docs/product/user-guide.ru.md) · [Поддержка](SUPPORT.md)

## Возможности

| | Mac | iPhone и iPad |
| --- | --- | --- |
| Голосовой ввод | Запуск сочетанием клавиш и вставка текста в другое приложение | Основной сценарий: запись и расшифровка встреч |
| Очные встречи | Запись через микрофон | Запись разговоров без компьютера |
| Онлайн-встречи | Компьютерный звук и микрофон с отдельным управлением микрофоном | Запись очных встреч через микрофон устройства |
| Локальное распознавание | Совместимая модель для обработки на Mac | Загрузка совместимой модели и обработка на устройстве |
| Работа с результатом | Текст, метки участников, поддерживаемые сводки и экспорт | История, прослушивание и текст с метками участников |

Совместимые модели поддерживают русский и английский. Другие языки, скорость и требования к памяти зависят от модели и устройства. Автоматические метки участников и сводки могут содержать ошибки: проверяйте важные результаты.

## Начало работы

1. [Скачайте установщик для Mac](https://github.com/Pichi-AI/pichi-voice/releases/download/v0.1.0%2B69-public.1/Pichi-Voice-0.1.0-69-macos-arm64.dmg) для Apple Silicon и macOS 15 или новее.
2. Откройте образ диска и перетащите Pichi Voice в «Программы». Запустите Pichi Voice из «Программ».
3. Пройдите первоначальную настройку, когда Pichi Voice откроется. Разрешите микрофон, Accessibility для ввода в другие приложения и запись экрана/системного аудио для компьютерного звука.
4. Выберите и загрузите модель для своего языка, пока есть интернет.
5. Сделайте короткую диктовку или запись и проверьте результат.

Для базовой локальной записи и совместимой расшифровки аккаунт Pichi не нужен.

Подробнее: [руководство](docs/product/user-guide.ru.md).

## Онлайн-встречи и ВКС

На Mac Pichi Voice записывает звук локально, без приглашения бота на встречу. Запись микрофона управляется отдельно от компьютерного звука.

В нативных проверках использовались Zoom и Google Meet. Запись звука, определение подключения к звонку и наблюдение за микрофоном ВКС имеют разные границы поддержки. Автоматическое наблюдение mute зависит от клиента, интерфейса и разрешений; оно не гарантирует работу без задержки во всех ВКС. Для прямого управления локальной записью используйте кнопку микрофона Pichi Voice.

Также изучались **Яндекс Телемост, Контур.Толк, МТС Линк, VK Teams и TrueConf**. Полные сценарии подключения и mute для них ещё проверяются. [Отчёт о совместимости](docs/research/communication-platforms-2026-11.md) сохраняет выполненные проверки и ограничения.

## Приватность и офлайн

Совместимые локальные модели обрабатывают аудио на устройстве после загрузки файлов. Базовая запись и расшифровка работают без аккаунта Pichi. Облачные AI-провайдеры и функции аккаунта/загрузки Pichi необязательны; при их выборе соответствующие данные могут передаваться выбранному сервису.

Загрузка моделей и дополнительные функции используют сеть. Экспортированные файлы подчиняются правилам выбранного приложения или хранилища. Проверьте хранение аудио и настройки обмена. Записывайте только разговоры, которые имеете право обрабатывать.

Подробнее: [обработка данных](docs/product/privacy.md) и [политика мобильного приложения](https://pichi.ai/ru/voice/privacy).

## Разработка

```sh
git clone https://github.com/Pichi-AI/pichi-voice.git
cd pichi-voice
bash scripts/dev/new-worktree.sh my-change
# Продолжайте в абсолютном каталоге worktree, который напечатает скрипт.
bash scripts/dev/setup.sh
bash scripts/dev/macos.sh build
```

Для нативных сборок нужен Xcode. Веса моделей загружаются отдельно по собственным лицензиям и не входят в репозиторий.
